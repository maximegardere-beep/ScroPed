✨ Génération par IA (Gemini)
Génère 1 fiche instantanément via l'API gratuite Gemini, pour tester rapidement. Ta clé reste stockée uniquement sur cet appareil.
🔄 Synchronisation GitHub
L'app va lire le dossier Recos de ton dépôt GitHub à chaque lancement. Chaque fichier nom.json devient automatiquement un module appelé "nom" dans le feed.
☁️ Publier vers GitHub
Envoie directement les fiches générées par l'IA ou importées manuellement (pas encore publiées) dans un nouveau fichier lotN.json du dossier Recos. Nécessite le token ci-dessus avec la permission Contents: Read and write.
💾 Sauvegarde locale
Tes données (posts importés, favoris, progression) vivent uniquement dans ce navigateur. Exporte régulièrement une sauvegarde pour ne rien perdre, ou pour la transférer sur un autre appareil.
📋 Générer un lot de fiches reco (25, via Claude/IA externe)
Copie ce prompt dans Claude (ou une autre IA) : elle choisit elle-même des recommandations variées, génère 25 fiches classées par thème, et te fournit un fichier lot.json — renomme-le toi-même en lotX.json (X = numéro suivant) avant de l'uploader dans le dossier Recos sur GitHub.
💊 Générer un lot de quiz posologie pédiatrique (20, via Claude/IA externe)
Même principe, mais façon Anki : la carte n'affiche que le nom du médicament, tu dois te rappeler la dose avant de révéler la réponse. Copie ce prompt, récupère le fichier, renomme-le lotX.json et uploade-le dans Recos comme les autres.
🩺 Générer un lot de repères et cas cliniques (20, via Claude/IA externe)
Cartes recto/verso : valeurs normales, scores, formules d'urgence et mini-cas cliniques à résoudre avant de révéler la réponse. Même procédure : récupère le fichier, renomme-le lotX.json et uploade-le dans Recos.
🛠️ Import manuel (dépannage)
Tu peux aussi coller un JSON directement ici plutôt que de passer par GitHub.
